# Portfolio · app de Next.js

Código del sitio de Ariadna Ramírez. La descripción completa del proyecto, cómo correrlo y cómo se despliega está en el [README principal](../README.md).

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # exporta el sitio estático a out/
npm run cv         # regenera los PDF del CV en public/cv
```
